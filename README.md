# Складской учёт (warehouse-inventory)

Учебный проект по курсу «Методология и практики DevOps», вариант №1 — складской учёт.

Стек: Python 3.11, FastAPI, PostgreSQL, SQLAlchemy + Alembic.
Команды проекта собраны в `Makefile` (`make setup`, `make run`, `make test`,
`make quality`, `make verify`).

Документация появится по мере выполнения лабораторной работы №1.
