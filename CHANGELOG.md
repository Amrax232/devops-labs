# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — семантические.

## [0.1.0] — 2026-09-10

Результат лабораторной работы №1.

### Добавлено

- HTTP API на FastAPI: единицы измерения, поставщики, материалы, поступления, отчёты.
- Реляционная схема из пяти связанных таблиц и миграция Alembic `0001_initial_schema`.
- Правило предметной области: проведение поступления изменяет остатки;
  проведённый документ неизменяем.
- Единый формат ошибок и обработка некорректных запросов (404/409/422).
- Конфигурация через переменные окружения, `.env.example`, health-check `/healthz` и `/readyz`.
- Автоматические тесты (pytest) и статический анализ (ruff).
- Единые команды проверки в `Makefile`, контейнерный PostgreSQL, скрипты backup/restore.
- Документация: ТЗ, описание API, схема БД, регламент внесения изменений.
